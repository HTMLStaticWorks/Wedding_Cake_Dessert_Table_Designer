Welcome

Complete guide to managing and customizing your Wedding Favor & Custom Gift Company website.

Welcome to Cherish & Co., a premium web template built for luxury wedding favors, personalized guest gifting, and bespoke monogram keepsakes. Built with clean HTML5, CSS3 variables, and vanilla JS for ultra-fast loading and full responsiveness.

Installation Guide

How to set up your website for local preview and live deployment.

Local Setup

Open the directory in any code editor (like VS Code) or double-click index.html to open directly in any modern browser.
